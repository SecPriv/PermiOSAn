# PermiOSAn: Mapping and Measuring iOS and Android Permissions Across Space and Time

Repository for paper under submission.

## Statistics and Measurements

To verify our numbers presented in tables and figures in the paper, follow these steps:

1. run `permission_analysis.py`
2. run `process_json.py`
3. run `filter_permission_diffs.py`
4. run `permission_analysis_statistics.py`
